Orientações:

projeto sobre design patterns

Disciplina: Paradigmas de Programação
Turma: CC5AN
Prof. Alex Carneiro

Entrega
A entrega do projeto deverá ser feita através de um repositório no Github, o qual deverá ser
de acesso público.
O repositório deverá conter todos os arquivos de código fonte e dados de modo que a
aplicação possa ser executada sem quaisquer configurações ou instalação de outros
softwares.

Requisitos
O projeto deverá conter dois módulos: um servidor e um cliente.
O servidor deverá ser desenvolvido com Flask e disponibilizar endpoints para acesso a
cada um dos recursos implementados.
O cliente deverá ser desenvolvido com uma interface gráfica com QT e acessar os
endpoints para enviar e receber dados do servidor.
Não será permitido usar banco de dados, APIs de terceiros, serviços de nuvem, serviços de
IA, etc.
Testes
Cada projeto terá testes próprios, os quais serão definidos ao longo das aulas.
Os testes deverão incluir:
- validação dos códigos do servidor e do cliente,
- comportamento do servidor e do cliente,
- demonstração final da aplicação em uso.
Documentação
A documentação entregue junto com os códigos fonte via Github deverá conter:
- diagramas de classes do cliente e do servidor,
- requisitos funcionais e não-funcionais,
- condições de aceitação.
